# Dub's genre changes (#131, spec §9.7, §21.3) over the sysex test port, in one boot: Psytrance into Dub and back out
# in all three styles, for the long tempo glide (Psytrance 138-146 BPM, Dub 70-80). Acid techno (the boot genre) cuts
# to Psytrance first. ROOTS DUB is a GENRE row of its own (no parent), so picking it opens the confirm at once, on
# BUILD INTO A DROP (its transition entry). The first change glides Psytrance's own Build (16 or 32 bars) down to
# Dub's tempo onto Dub's Drop, which sounds; a forced Break in Dub keeps the kick, Rim and Bass sounding; the last
# change out of Dub plays Dub's 1-bar Build, gliding about 75 -> 142 BPM in about 2.2 s (spec §9.7: a deliberate slam),
# into Psytrance's Drop. Every start checks the glide arrived where the new roster starts: tempo_off (the song's
# tempo against the incoming Recipe's, in hundredths of a BPM) under 10 BPM. It is read at the start step's decision
# tick, 12 ticks early, where a fast glide is still 2-3 BPM short; a glide that never ran is 58 BPM or more off. A hard
# cut glides at the GLIDE setting (spec §13.3): the cuts' bound assumes its default, 1 bar, which it is after boot
# (it's kept until power-off); with 2 bars or longer a cut's glide is still far off where the new roster starts. Runs
# on a Deluge (deluge_probe.py session) or in delugemu (test_port_emu.py). Start as after boot: transport stopped, GLIDE
# at 1 bar, the current clip a synth or kit clip.
#
# Order: Acid -> Psytrance CUT, -> Dub BUILD (the highlight: Psytrance's Build), a Break in Dub, -> Psytrance CUT,
# -> Dub FADE (Psytrance's 1-phrase Outro), -> Psytrance FADE (Dub's 1-phrase Outro), -> Dub CUT, -> Psytrance BUILD
# (Dub's 1-bar Build). Dub's phrases are 24-27 s, Psytrance's 26-28 s and its Builds 27-55 s: the waits are long.
# gen_confirm <genre> style=<0 drop|1 fade|2 cut> result=<0 started>; gen_outputs_freed ... total=N counts the outgoing
# roster's Outputs: Acid techno's 4, Psytrance's 6, Dub's 5.
# For figures: --events 'gen_confirm|gen_transition|gen_section|gen_h1|gen_h16|gen_outputs_freed'.
