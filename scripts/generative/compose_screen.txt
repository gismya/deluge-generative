# The Compose screen (#137, spec §14.4, §14.5) over the sysex test port: it opens over the view with only FROM until a
# Recipe exists; FROM → GENRE rolls one; then every row edits the Current Recipe (TEMPO, SWING, KEY and SCALE (in place),
# the four macros, SEED + TAKES with NEW SEED and a take, SOUNDS with a lane's and a part's re-roll and SHIFT+push back
# to the previous pick, REGENERATE? keeping the macros, LENGTH), a Recipe replaced in Perform forgetting the previous
# picks (gen_compose_pick <row> none: NO PREVIOUS SOUND), and BUILD asks DISCARD SONG? and builds at LENGTH; a
# build cancelled on COMPOSING leaves the screen open.
# The test port's "compose screen" line opens it with no Recipe (the Generative menu's COMPOSE FROM always has one by
# then); the stale-picks step goes through PERFORM FROM and COMPOSE FROM's CURRENT RECIPE (gen_from_menu).
#
# gen_compose_recipe <why> genre= tempo= swing= key= scale= macros= and gen_compose_seed <why> seed= takes= length=:
# the Current Recipe after an edit (why: the row, or opened/rolled/seed). gen_compose_pick <row> path=: a SOUNDS row's pick after it changed.
# gen_recipe_roll <genre|regenerate|part|lane> done|cancelled|failed: a card-reading edit ended. Rows are chosen from
# the top (encoder 3 -20): FROM, REGENERATE, SEED + TAKES, TEMPO, SWING, KEY, SCALE, ENERGY, DENSITY, COMPLEXITY,
# MOTION, SOUNDS, LENGTH, BUILD.
