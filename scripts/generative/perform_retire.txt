# Retiring Outputs and the UI (#194, spec §12.9, §13.7, §13.8) over the sysex test port. Perform's pump asks the view
# to let go of an Output before it goes to the free job: the gold knobs move off it, a sound editor on it closes, and
# an Output with a UI over its editor waits. Just before it frees an Output, a test build checks by identity that the
# knobs, the song's current Clip and every sound-control set are off it; if one isn't it sends
# gen_retire_referenced by=knobs|current_clip|sound_controls and frees nothing more until Perform is left. No case
# here but the last expects that event. Runs on a Deluge (deluge_probe.py session) or in delugemu (test_port_emu.py).
# Start as after boot: transport stopped, the current clip a synth or kit clip.
#
# Techno's parts: DRUMS row 1 (y 7, a Kit), ACID row 2 (y 6, a synth). The cases perform_sound_editor.txt has (a swap
# and a new roster under the sample browser) and perform_clip.txt has (a swap on a focused and on a locked part) are
# not repeated.
# hold free: the free job waits at its start. hold reactions: the view skips its own reactions to a swap and a new
# roster (the knob rebind, the focus drop, the editor closing), so only the pump's release is left. hold ui_release:
# the pump doesn't ask the view.
start_state
include perform_open.txt
include perform_confirm.txt
