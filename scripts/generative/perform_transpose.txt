# Pitched parts load at whole-sound transpose 0 (#311, spec §10.6, ADR 0007), in delugemu (test_port_emu.py
# --card-overlay scripts/generative/fixtures/perform_transpose) or on a Deluge whose card has the same override and
# preset. Acid techno's override makes ACID 047 Basic Dirty Bass, saved at -24, and the Impact lane the pack's GEN
# Impact synth, saved at -12. ACID plays the -24 preset at 0, and then 097 Saturated Filter (saved at 0, chosen in the
# preset browser) at 0 too, so the same note sounds in the same octave on both; DRONE plays at 0; the Impact synth
# keeps its -12. Kit sample rows have no whole-sound transpose to keep.
#
# gen_sound_transpose PART LANE saved=<the preset's whole-sound transpose> played=<after the load-time settings>
# (LANE "-" for a synth part). Acid techno's parts: DRUMS row 1 (y 7), ACID row 2 (y 6), DRONE row 3, FX row 4.
# The QWERTY keyboard's digits are row y 5, '1' to '0' at x 3 to 12: "097" is x 12, 11, 9.
# needs: card fixtures/perform_transpose (its own card, above; test_port_emu.py builds it)
# covers: src/deluge/generative/firmware/perform_song.* src/deluge/generative/firmware/card_sounds.*
# covers: src/deluge/generative/firmware/sound_swaps.* src/deluge/generative/perform/sound_swap_lifecycle.h
# covers: src/deluge/generative/firmware/current_recipe.* src/deluge/generative/core/sound_settings.h

expect event gen_sound_transpose ACID - saved=-24 played=0 within=20

expect event /gen_sound_transpose DRONE - saved=-?\d+ played=0/ within=20
expect event gen_sound_transpose FX IMPACT saved=-12 played=-12 within=20
expect event gen_sound FX IMPACT pick mode=0 prio=0 SYNTHS/GENERATIVE/FX/GEN Impact.XML within=20
expect event gen_perform_entered within=20
expect root_ui=generative_perform within=10
expect playing=false
