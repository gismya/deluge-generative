# The sound editor inside Perform (#116, spec §13.5, §13.7, F6, F7) over the sysex test port: SHIFT + a main pad opens
# it at the printed param, on the focused part's Sound or with nothing focused the song FX, and SOUND EDITOR on the
# CLIP page opens the part's root menu. Pads, PLAY and the gold knobs stay live under it, with no grey-out, and its
# edits set homes. It never makes Perform a ClipMinder: SAVE, KEYBOARD and CLIP do nothing, SONG closes it back to the
# SONG page, BACK closes it, and a sound swap on its part closes it. Runs on a Deluge (deluge_probe.py session) or in
# delugemu (test_port_emu.py). Start as after boot: transport stopped, the current clip a synth or kit clip.
#
# Techno's parts: DRUMS row 1 (y 7, a Kit), ACID row 2 (y 6, a synth). Pad 8 7 is LPF FREQUENCY for a Sound, the song
# and a Kit's affect-entire FX alike. gen_editor open part=<p|-1> kit=0|1 greyout=0|1: Perform opened the editor (or
# moved it to another param), greyout as it opened (SHIFT's stock shortcut overlay greys the pads while SHIFT is
# held). gen_editor stayed song|part: a SHIFT + pad didn't move it. gen_editor retired: a sound swap or a new roster
# closed the one open on a part it replaced. gen_editor closed: Perform is on top again. Test builds fault on any null
# access, so a stock read of the song's current Clip (none in Perform) fails the run.
start_state
include perform_open.txt
include perform_confirm.txt

# ---- Nothing focused, stopped: SHIFT + LPF FREQUENCY opens the song FX there, over Perform ----
button SHIFT down
wait 50
pad 8 7 down
wait 50
pad 8 7 up
wait 300
button SHIFT up
expect event gen_editor open part=-1 kit=0
expect ui=sound_editor
expect root_ui=generative_perform
encoder 3 2
encoder 3 -2
# LEARN held and a gold knob turned: a fault check, since the song FX have no Output to learn the knob's page on
button LEARN down
wait 50
encoder 4 1
wait 50
button LEARN up
wait 50
# Pads stay Perform's: holding ACID's row focuses it under the editor, which stays open
pad 3 6 down
expect event gen_focus part=1 locked=-1
expect ui=sound_editor
pad 3 6 up
expect event gen_focus part=-1 locked=-1
# Holding ACID's row, SHIFT + a pad with no Sound param yet (a stock "coming soon"): the editor stays on the song FX
wait 500
pad 3 6 down
expect event gen_focus part=1 locked=-1
button SHIFT down
wait 50
pad 4 2 down
wait 50
pad 4 2 up
wait 300
button SHIFT up
expect event gen_editor stayed song
expect ui=sound_editor
encoder 3 1
encoder 3 -1
# Still holding it, SHIFT + LPF FREQUENCY moves the editor onto ACID's Sound
button SHIFT down
wait 50
pad 8 7 down
wait 50
pad 8 7 up
wait 50
button SHIFT up
expect event gen_editor open part=1 kit=0
encoder 3 1
encoder 3 -1
pad 3 6 up
expect event gen_focus part=-1 locked=-1
button BACK down
wait 50
button BACK up
expect event gen_editor closed
expect ui=generative_perform
