# #388: does Perform entry's Generator land in SDRAM after a large Compose song, and does that slow step decisions
# (H1, spec §20)? Perform entry allocates its two Generator blocks with allocMaxSpeed while the old song is still
# loaded; a 20:00 Compose song can leave the internal heap nearly full (H19: about 89 K free).
# Two Perform entries on Acid techno, each played into a forced Groove for four gen_h1 reports (16 bars):
#   1. a normal entry, from start_state's blank song;
#   2. an entry after a 20:00 Psytrance Compose song (the H19 build), saved and loaded back with the built song still
#      current, as compose_h19.txt does: the state #388 saw, with the internal heap down to about 89 K.
# hold entropy before each entry pins its roll, so both enter the same Acid techno piece (their gen_sound events
# match, as in perform_entropy.txt). H1's windows start again with each entry's piece; the four read cover the
# Groove's first 16 bars (the two before them are the Intro's).
# gen_generator_heap gives each block's heap (internal or sdram) and its address range, with the internal heap as the
# allocation found it: free bytes (internal_free) and the internal general region's largest free span (largest_span),
# which is what decides whether a block fits; gen_mem before_entry the regions as entry starts. Compare H1's mean_ns
# between the two.
# Runs on a Deluge (deluge_probe.py session) or in delugemu (test_port_emu.py). Start as after boot: transport stopped,
# the current clip a synth or kit clip.
# Each run writes SONGS/H388 PSYTRANCE.XML on the card.
# needs: a Deluge for its timings, and about 5 minutes in delugemu, so check_all.py skips it
# For figures: --events 'gen_generator_heap|gen_mem|gen_h1|gen_h16|gen_section|gen_compose'.
# covers: src/deluge/generative/firmware/entry_leave.cpp src/deluge/generative/firmware/compose_job.cpp
# covers: src/deluge/generative/firmware/adapter_timing.h src/deluge/generative/firmware/output_sink.cpp
# covers: src/deluge/generative/core/genres/techno.cpp src/deluge/generative/core/types.h
# covers: src/deluge/gui/context_menu/generative.cpp src/deluge/gui/menu_item/generative/perform_menu.cpp
# covers: src/deluge/gui/views/perform_view_clip.cpp src/deluge/gui/views/perform_view_song.cpp
# covers: src/deluge/generative/core/lane_names.h src/deluge/generative/firmware/perform_song.cpp
# covers: src/deluge/generative/firmware/free_memory.h src/deluge/generative/firmware/adapter_timing.cpp
# covers: src/deluge/generative/firmware/perform_adapter.cpp
start_state
hold entropy

# ---- 1. A normal entry, from a blank song ----
mark now
include perform_open.txt
include perform_confirm.txt
keep events /^gen_sound /
expect event /^gen_generator_heap block=0 (internal|sdram) start=0x[0-9a-f]{8} end=0x[0-9a-f]{8} internal_free=\d+ largest_span=\d+$/ since=mark
expect event /^gen_generator_heap block=1 (internal|sdram) start=0x[0-9a-f]{8} end=0x[0-9a-f]{8} internal_free=\d+ largest_span=\d+$/ since=mark
include perform_after_compose_groove.txt
include perform_leave.txt

# ---- 2. An entry after a 20:00 Compose song, saved and loaded back ----
compose 1200 psytrance
expect event /^gen_compose done ran=1 / within=600
expect ui=arranger within=10
save song H388 PSYTRANCE
expect event song_saved name=H388 PSYTRANCE within=300
load song SONGS/H388 PSYTRANCE.XML
expect event song_loaded path=SONGS/H388 PSYTRANCE.XML within=300
expect root_ui=arranger within=10
hold entropy
button SESSION_VIEW down
wait 100
button SESSION_VIEW up
expect ui=session within=10
expect playing=false
wait 1000
mark now
button SHIFT down
wait 100
button SESSION_VIEW down
wait 100
button SESSION_VIEW up
wait 100
button SHIFT up
expect ui=context_menu
expect root_ui=session
include perform_pick_acid.txt
include perform_confirm.txt
expect events kept within=10
expect event /^gen_generator_heap block=0 (internal|sdram) start=0x[0-9a-f]{8} end=0x[0-9a-f]{8} internal_free=\d+ largest_span=\d+$/ since=mark
expect event /^gen_generator_heap block=1 (internal|sdram) start=0x[0-9a-f]{8} end=0x[0-9a-f]{8} internal_free=\d+ largest_span=\d+$/ since=mark
include perform_after_compose_groove.txt
include perform_leave.txt
