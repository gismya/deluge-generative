# Perform's preset browser (#299, spec §10.7, §13.5) over the sysex test port: SYNTH on a focused synth part opens it on
# the part's pick, scrolling loads nothing, BACK closes it with nothing changed, and a chosen preset (here one ACID's
# palette doesn't list) preloads and swaps in as a re-roll does: on the next phrase line while playing, at once while
# stopped. Perform's sidebar under it (mutes, solos, forces; End doesn't arm), a BACK hold that only closes it (a hold
# on Perform after it still opens LEAVE PERFORM?), and End waiting that a release or a tap under it doesn't cancel. Its
# cancels (SYNTH, NEW SOUND, BACK taps), its refusals (at SYNTH, and at SELECT with the browser left open), the previous
# sound after it (SHIFT + SYNTH, SHIFT + NEW SOUND), NEW SOUND, a Regenerate and a genre change after it, and SYNTH on a
# Kit part and KIT, which still re-roll. Runs on a Deluge (deluge_probe.py session) or in delugemu (test_port_emu.py).
# Start as after boot: transport stopped, the current clip a synth or kit clip.
#
# Acid techno's parts: DRUMS row 1 (y 7), ACID row 2 (y 6), DRONE row 3, FX row 4. The QWERTY keyboard's digits are
# row y 5, '1' to '0' at x 3 to 12: typing "002" (x 12, 12, 4) jumps to SYNTHS/002 Basic Square Bass.XML
# (perform_choose_002.txt does it all, from SYNTH to SELECT).
# gen_browser open part= pick=<the part's pick> at=<the selected file>; gen_browser at=<folder>/<file> on each move;
# gen_browser chose part= path=; gen_browser closed. gen_press browser|chosen|sound part= previous= result=<0
# preloading|1 cancelled|2 busy|5 change pending> working=. gen_sound_press and gen_sound_preload say
# source=roll|previous|chosen. gen_sidebar ... force=<G|B|U|-> ... end=<q|->[+]: the sidebar's state (+: End's pad lit). ACID's palette: 005 Sweet Mono Bass
# alone.
