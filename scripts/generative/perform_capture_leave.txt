# Building on leave (#146, spec §13.8, §17.7) over the sysex test port: the leave menu's options follow the marks, and
# a keep choice builds the kept pieces behind the teardown, one song at a time, saves each to SONGS/ as
# GEN <GENRE> <seed code> LIVE (a name already on the card takes a letter: LIVE B, LIVE C), and lands on the last
# saved song in arranger view. The songs then load back on a Deluge with nothing else in memory. Writes three songs to
# SONGS/ (GEN ACID TECHNO 3E9D8DZ LIVE, LIVE B and LIVE C; a run on a Deluge deletes them after). Runs on a Deluge (deluge_probe.py session) or in
# delugemu (test_port_emu.py). Start as after boot: transport stopped, the current clip a synth or kit clip.
#
# gen_leave_menu open: the menu is up. gen_capture_begin keep=N: Capture is queued behind the teardown (LeaveOption N).
# gen_capture_piece songs= notes= nodes= cuts= tracks= dropped= off_scale= edits_dropped=: a piece replayed.
# gen_capture_held: the build waits after its first bar ("hold compose"). gen_capture_song n= of= error= name=: a song
# saved (error=0) or not. gen_capture_end done|cancelled|failed songs= saved= ms= error= name=: Capture ended, and the
# song it landed on. "hold compose_reserve" makes the build find the SDRAM reserve reached (error=1, INSUFFICIENT_RAM).
# covers: src/deluge/generative/firmware/capture_job.* src/deluge/generative/firmware/song_file.*
# covers: src/deluge/generative/firmware/compose_song.* src/deluge/generative/firmware/entry_leave.cpp
# covers: src/deluge/generative/perform/capture.* src/deluge/gui/context_menu/generative.*
# covers: src/deluge/gui/ui/generative_modal.* src/deluge/generative/compose/compose_driver.*
# covers: src/deluge/generative/compose/clip_builder.* src/deluge/generative/firmware/log_header.*
# covers: src/deluge/generative/firmware/sound_controls.* src/deluge/gui/views/perform_view.*
# covers: src/deluge/generative/firmware/perform_adapter.* src/deluge/gui/l10n/english.json
# covers: src/deluge/gui/l10n/g_english.cpp src/deluge/gui/l10n/strings.h
